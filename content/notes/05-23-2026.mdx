## Lists

Unordered:

- Gradient descent minimizes a loss function
- Backpropagation computes gradients via the chain rule
- Learning rate controls step size

Ordered:

1. Forward pass — compute predictions
2. Compute loss
3. Backward pass — compute gradients
4. Update weights

Nested:

- Optimization
  - First-order methods (SGD, Adam)
  - Second-order methods (Newton, L-BFGS)
- Regularization
  - L1 / L2 weight penalties
  - Dropout

## Math — inline

Inline math sits inside single dollar signs: the softmax of logit $z_i$ is

$\sigma(z)_i = \dfrac{e^{z_i}}{\sum_j e^{z_j}}$

and the cross-entropy loss for a single example is $\mathcal{L} = -\log \sigma(z)_y$ where $y$ is the true class.

## Math — display blocks

Use double dollar signs for a centred equation block.

The multivariate Gaussian density:

$$
p(\mathbf{x}) = \frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}}
\exp\!\left(-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^\top \Sigma^{-1}(\mathbf{x}-\boldsymbol{\mu})\right)
$$

Bayes' theorem:

$$
p(\theta \mid \mathcal{D}) = \frac{p(\mathcal{D} \mid \theta)\, p(\theta)}{p(\mathcal{D})}
$$

The normal equations for least-squares regression:

$$
\hat{\boldsymbol{\beta}} = \left(X^\top X\right)^{-1} X^\top \mathbf{y}
$$
